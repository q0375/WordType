## 二、全局基础约定
| 约定 | 定义 |
|------|------|
| 切日 | 一切「今日/每日/连续天数」按 D13 时区，切日点 00:00 |
| user_id 来源 | 所有端点的 user_id 一律从 JWT 解析，禁止接受 body/query 中的 user_id |
| 判定基础 | 去首尾空格、统一小写；严格=完全匹配；宽松（默认开）= Levenshtein ≤1 判近似 |
| 错误响应 | 统一 {code, message, detail?}，HTTP 状态码语义化 |
| 分页 | ?page=1&page_size=50（上限 200）；大列表可选游标 ?cursor= |
| 幂等 | POST /exam/submit、/game/submit 必须携带 Idempotency-Key（uuid）请求头；学习/练习/复习单题提交携带 body.request_id（客户端 uuid），断网重放按 request_id 24h 去重（D19）〔v3.1〕；重复请求返回首次响应〔v3.1，口径 24〕 |
| WPM 公式 | WPM = 正确字符数 ÷ 5 ÷ 有效输入分钟数。有效输入分钟数 = 该题首键→末键墙钟时间；默写卡展示期、等待期不计；游戏为整局有效输入时长（暂停剔除）〔v3.1，口径 13〕 |
| 准确率 | 正确击键数 / 总击键数；错误击键计入分母，退格键不计 |
| 逐字母延迟 | 相邻两次 keydown 的时间差，用于热力图与 LetterStat |
| 日期展示 〔v3.1〕 | 前端一切「今日/连续天数/额度」以服务端返回的 date 字段为准，禁止本地 new Date() 自算（P0 验收④保障） |
## 三、项目概述
集背单词与打字速度练习于一体的 Web 应用。核心价值：以打字为练习手段、以间隔复习为记忆引擎、以游戏化激励为动力、以数据统计与 AI 建议为导航。
技术栈（确定）：
- 后端：Python FastAPI + SQLAlchemy（异步）+ APScheduler（定时任务）
- 数据库：SQLite（WAL 模式，busy_timeout=5000，写失败指数退避重试 3 次）→ 预留 PostgreSQL 迁移
- 前端：Vue 3 + Vue Router + Pinia + Element Plus + Axios + Vite（游戏用 Canvas 2D，图表用 ECharts）〔v3.3 实际落地，v3.2 的 React 19 方案未采用〕
- 认证：JWT（前端 localStorage 按 {userId}: 前缀隔离缓存）
- AI 建议：P3 规则引擎；P4 可选 LLM（OpenAI 兼容协议，每用户自有凭据接入，D28/D29）〔v3.3〕
- 发音：服务端 edge-tts 合成 mp3（美音 en-US-AriaNeural / 英音 en-GB-SoniaNeural），磁盘缓存；GET /api/v1/tts 匿名音频端点（audio 标签无法携带鉴权头）；前端 SpeechSynthesis 兜底〔v3.3〕
- 部署：Uvicorn + Nginx（公网强制 HTTPS）
约束：不使用 Java；所有用户数据严格按 user_id 隔离。

题型（可勾选组合，范围 = 章节选择）：
| 题型 | 说明 |
|------|------|
| 释义 → 打字默写英文 | 默认 |

出题算法：
- 勾选题型均匀轮询出题，某题型可用池为空时自动跳过并按比例补偿
- 答错的词在本组练习内以 50% 概率重现，插入本组题队尾部（D23）〔v3.1〕
- 组规格（D23〔v3.1〕）：每组默认 20 题（可配 10–50）+ 手动结束（已答部分正常计分）；同词组内除重现一次外不重复
判定规则（全局约定，用户可设置严格/宽松）：
1. 去除首尾空格，统一小写比较
2. 严格模式：完全匹配才算对
3. 宽松模式（默认开）：Levenshtein ≤1 判「近似错误」→ 按答错计熟练度惩罚（p−12），但不重置复习间隔、不重现；streak 不清零不增长（D21）〔v3.1〕
打字专项：
- 指法引导：虚拟键盘高亮下一字母 + 手指分区颜色（可关闭）
- 实时统计：本组 WPM、准确率、逐字母延迟热力图（公式见第二章/附录 C）
- 中断保护（D12）：进度每 30 秒写 localStorage，重新进入本机可恢复；不做服务端续练
- 断网重放（D19〔v3.1〕）：单题提交失败进 pending 队列（localStorage，同 {userId}: 前缀），恢复网络自动重放；请求携带 request_id（uuid），服务端 24h 幂等去重。考核除外（中断即作废）
结果页：逐词对错列表，错词一键加入错题本。
单题实时提交（D9），前端逐题上报 TypingRecord（含 source=practice、detail_json 逐字母时间戳，供 LetterStat 聚合〔v3.1〕）。

### 模块 7：数据指标与仪表盘
熟练度算法（定稿）：
- 初始值 0；自评设值：认识=60，模糊=30，不认识=0（D8，仅学习模式）；设值后 streak=0（D21）〔v3.1〕
- 答对：proficiency = MIN(100, proficiency + 10 × MIN(streak_correct, 3))；streak+1〔v3.1〕
- 答错：proficiency = MAX(0, proficiency − 25)；streak 清零〔v3.1〕
- 近似错误：proficiency = MAX(0, proficiency − 12)；streak 不清零不增长〔v3.1〕
- 状态：≥80 已掌握（next_review_at 置 NULL，退出复习循环）；40–79 巩固中；<40 高危遗忘
- **已掌握回退（D18〔v3.1〕）**：已掌握词在任意模式答错致 p<80 → 状态回「巩固中」，interval 重置 1 天、next_review_at=+1d、ease 沿用（下限 1.3），重新入复习队列（已同步附录 A）
- 「N 天后低频重检」为 P4 可选，默认关
打卡定义：当日任一模式完成 ≥1 次有效提交（自评/答题/交卷/游戏结算）即打卡。**数据写入〔v3.1 口径 21〕**：提交时实时 upsert DailyActivity（当日打卡/热力图即时可见），04:00 任务仅做对账校准。
记录维度：熟练度、总次数、对/错/近似次数、错误率、连对、最近对错时间、WPM、准确率。
仪表盘：今日待复习数、今日新学数、连续天数、打卡热力图（DailyActivity 预聚合）、熟练度分布饼图、WPM/准确率趋势（TypingRecord.source 支持按模式区分〔v3.1〕）、未来 7 天复习量条形图。
### 模块 8：复习循环（SM-2）
- ease 初始 2.5，下限 1.3；间隔序列 1天 → 3天 → 之后 = 上次间隔 × ease
- 答对：间隔推进，ease +0.05（上限 3.0）
- 答错：间隔重置 1 天，ease −0.2；该词当日队列重现一次（D11，可关）
- 近似错误：间隔减半（不低于 1 天），ease −0.1；不当日重现
**复习形式与自评映射（D16〔v3.1〕）**：复习形式可配置——打字默写（默认）/ 选择 / 自评。形式=自评时：
| 复习自评 | 映射处理 |
|---------|---------|
| 认识 | 按答对处理：间隔推进、ease+0.05、streak+1、p+10×MIN(streak,3) |
| 模糊 | 按近似错误处理：间隔减半（≥1天）、ease−0.1、p−12、streak 不变、不当日重现 |
| 不认识 | 按答错处理：间隔重置 1 天、ease−0.2、p−25、streak 清零、受 D11 开关控制当日重现 |
**释义显示（D34〔v3.5〕）**：复习作答是否展示释义提示由用户设置 `review_show_meaning`（默认开）控制：开启时打字默写显示中文释义与音标（看义默写）；关闭时不显示释义、仅听发音默写。选择形式（释义为作答目标）与自评形式（展示拼写、回忆释义）不显示释义提示；答题反馈区始终展示正确答案（拼写+音标+释义）。
流量：每日新词上限 20（可设 0–100）、复习上限 100（可设）；溢出顺延次日，按逾期天数降序补。
出题顺序：逾期词 → 高危遗忘 → 巩固中。
单词生命周期状态机：见附录 A（v3.1 已更新 D17/D18 路径）。
### 模块 9：游戏模式（下坠打字）
核心规则（D1，交互协议详见附录 B）：
- 单词从顶部下落，逐字母实时匹配：输入即锁定目标词；被锁定的词冻结下落，其余词继续
- 锁定优先级：已敲字母的词 > 未敲词；同级取离底部最近
- 敲对字母前进；敲错字母闪红但仍计入输入串，可退格（退格不扣血、不断 Combo，计入准确率）
- 输入串长度 = 词长时自动判定（无提交键）：完全正确（或宽松规则内）→ 销毁得分；否则 → 扣血 + 该词弹回顶部重新下落
- 落地未打完 → 扣血（默认 5）；落地与敲错提交均断 Combo；退格不断
计分（口径 19〔v3.1〕）：
- 打对加分 = (10 + 词长 × 2 + 高度加成) × Combo 倍率
- 高度加成 = round(10 × 剩余高度 ÷ 初始高度)，销毁时刻计算
- Combo 阶梯：连对 5 词→×1.5、10 词→×2.0、15 词→×2.5、20 词→×3.0（上限）；「无错」指无落地、无弹回
**开局协议（D27〔v3.1〕）**：POST /api/game/start 携带章节勾选+难度+模式；服务端执行词池抽取（高危遗忘词优先 30%，池内不足时取全部高危 + 随机补齐；前端不可信）并生成 session（30 分钟有效）；submit 携带 session_id，校验 word_id∈池、session 未结算。**中断（关页面无结算）→ 不入库、不入错题本**〔v3.1〕。
其他：
- **沉浸式对局 UI（D31〔v3.3〕）**：点「开始游戏」后整页切换深色渐变沉浸模式（顶部导航上收，鼠标悬停浮现），配置/结算页保持常规浅色；游戏区 85% 宽度居中；一体化悬浮状态栏：生命值（掉血红闪）+ 大号分数 + 金色连击徽章（连击跳动）+ 倒计时 + 暂停圆形按钮（带剩余次数角标）；暂停时画面模糊 + 居中面板（继续游戏/重新开始/退出游戏，退出=立即结算）；底部输入条仅锁定单词后出现，目标词逐字符高亮（正确黄/错误红/未输入灰），输入正确闪绿光、错误闪红光+轻震
- **按键音效（D31〔v3.3〕）**：WebAudio 合成（正确 880Hz / 错误 200Hz），设置页开关 `game_key_sound`（默认开）
- **开局校验（D31〔v3.3〕）**：必须先选择词库才能开始（未选时「开始游戏」按钮禁用并提示）；章节可选（不选=整本词库）
- 下坠速度随时间/分数递增；同屏词数 1→3；难度三档（初速/加速度/同屏数），难度可在配置页直接选（不必进设置页）
- 整局血条制，提供 3 分钟限时开关（无尽模式不显示计时；限时模式显示倒计时）；暂停每局 2 次（限时模式暂停即停表〔v3.1〕）

### 模块 10：AI 建议
P3 规则引擎版：每日首次登录生成并缓存（按 D13 切日），可手动刷新。**优先级〔v3.1 口径 20〕**：按固定顺序取前 3 条——① 错误率>60% → ② 高危明日到期 → ③ 连续 7 天未学 → ④ 指法专项。每条附一键执行按钮：
1. 错误率 >60% 的词共 N 个 → 立即专项练习
2. 高危遗忘词明日到期 N 个 → 现在复习
3. 连续 7 天未学习 → 今日 10 分钟轻量计划
4. 打字：LetterStat 最慢/最常敲错字母组合 Top 5 → 指法专项（数据源：LetterStat 单字母与 bigram 独立聚合，组合 Top5 取 bigram 行，D24〔v3.1〕）
展示：仪表盘顶部卡片，最多 3 条。
**P4 LLM 版（默认规则引擎，用户自选，D28/D29/D30〔v3.3〕）**：OpenAI 兼容协议（/chat/completions）自定义接入，不绑定供应商。**凭据每用户自有**（新表 UserAiConfig）：api_base_url / api_key（AES-GCM 加密存储，永不回显明文）/ model_name / temperature / timeout（默认 30s）；用户级端点 GET/PUT /api/ai-config（key 回显脱敏 ****尾 4 位）+ POST /api/ai-config/test 连通性测试；管理员不再配置 AI（原 /api/admin/ai-config 已删除）。**引擎选择**：用户设置项 `advice_engine`（规则引擎 / AI 模型，默认规则），切换后当日缓存立即失效。**生成流程（D30）**：选 AI 时首次访问立即返回规则建议占位（note=「AI 建议生成中」），后台调用 LLM（基于真实学习数据：高错误率词、高危到期数、活跃天数、弱指法、近 7 天 WPM/正确率），成功后覆盖缓存、前端轮询自动替换；LLM 调用失败自动重试 1 次，仍失败回落规则引擎并在仪表盘展示回退原因（advice_cache.note，悬停 ⓘ 查看详情）。手动刷新限 3 次/人/日；出域数据最小化（仅统计聚合与单词拼写，不含 user_id/username）；API 生成自然语言周报（规划中）。

```

   session（30 分钟有效）；submit 校验 word_id∈池

2. 被锁定词冻结下落；其余词继续下落
3. 敲对：匹配指针 +1；敲错：闪红、指针不动、错误字符入输入串（可退格）
4. 输入串长度 == 词长 → 自动判定：
     匹配（含宽松）→ 销毁，加分 = (10 + 词长×2 + round(10×剩余高度÷初始高度))
                      × Combo 倍率（连对 5→×1.5 / 10→×2.0 / 15→×2.5 / 20→×3.0 上限）
     不匹配         → 扣血 1，该词弹回顶部重下落（Combo 清零）
5. 任一词触底 → 扣血 1（Combo 清零）；血量 0 → 结算
6. 退格：删除末字符，不扣血、不断 Combo，计入准确率分母
7. 锁定词被消灭/弹回后 → 释放锁定，回到步骤 1
8. 中断（关页面无结算）〔v3.1〕→ 成绩不入库、不入错题本
```
