## 项目经历

### WordType · 打字背单词系统（个人全栈项目）

**项目时间**：2026.05 – 2026.09
**技术栈**：Vue 3 + TypeScript + Vite + Pinia + Element Plus + ECharts + Canvas / FastAPI + SQLAlchemy(async) + SQLite + APScheduler + JWT + edge-tts
**项目定位**：集单词记忆与打字速度训练于一体的 Web 应用，将背单词过程转化为打字输入，通过游戏化机制提升学习动机。支持 12 个功能模块、3 种学习模式、4 种练习题型、1 款 Canvas 打字游戏。

**项目架构**：
- 前端采用 Vue 3 + TypeScript 单页应用，按功能域划分 16 个视图组件，核心逻辑（判定引擎/游戏引擎/离线队列/主题系统）封装为独立 TS 模块，与框架解耦
- 后端采用 FastAPI 异步框架，按路由分层（api/v1/endpoints）+ 领域服务层（domain）+ 数据访问层（db），全局中间件链处理鉴权/限流/幂等/错误
- 数据库采用 SQLite WAL 模式，设计 15 张数据表，含用户域、词库域、学习域、游戏域、统计域、AI 建议域，支持软删除留痕与级联清理

**核心工作与技术亮点**：

**1. Canvas 60fps 打字游戏引擎（独立于 Vue 框架）**
- 设计纯 TS 游戏引擎类，通过事件订阅（`onSettle`/`onProgress`）与 Vue 组件通信，避免 rAF 与响应式调度冲突
- 实现单词下坠运动、锁定机制、连击阶梯加分、生命值系统、粒子爆炸特效、限时模式倒计时
- 服务端防作弊校验：每词提交携带首键/末键时间戳，服务端校验输入耗时 ≥ 词长×40ms，异常卷标记无效不入库
- 游戏对局采用沉浸式深色 UI：导航上收、一体化悬浮 HUD、暂停模糊遮罩、WebAudio 合成按键音效（880Hz/200Hz）

**2. SM-2 间隔重复算法与多模式学习引擎**
- 实现 SM-2 算法核心：熟练度（proficiency）、间隔（interval）、易度因子（ease）、连续答对（streak）四变量联动
- 支持 3 种学习模式：学习模式（自评卡 + 默写卡）、练习模式（4 种题型 + 错词 50% 重现）、复习模式（SM-2 调度 + 自评映射）
- 设计已掌握回退机制：p≥80 的词答错致 p<80 → 状态回退「巩固中」，interval 重置 1 天
- 错题本攻克计数：连续答对 3 次自动移出，支持手动置顶/移入/移出

**3. 幂等性与离线可靠性设计**
- 考核交卷、游戏结算等关键端点强制要求 `Idempotency-Key` 请求头，服务端记录 24h 内的幂等键，重复请求直接返回首次结果
- 前端离线重放队列：单题提交失败时存入 localStorage pending 队列（`{userId}:` 前缀隔离），网络恢复后自动按序重放
- 练习断点续练：当前组进度实时持久化，刷新页面后恢复到未完成的题目位置

**4. 异步 AI 建议系统与用户级密钥加密**
- 设计规则引擎 + 可选 LLM 双引擎：规则引擎按固定优先级（高错误率→高危到期→不活跃→弱指法）取 Top3 建议
- LLM 建议采用异步生成模式：首次请求立即返回规则占位（note="AI 建议生成中"），后台 `asyncio.create_task` 调用 LLM，完成后覆盖当日缓存；前端每 4s 轮询自动替换展示
- LLM 调用失败自动重试 1 次，仍失败回落规则引擎并将原因写入 `advice_cache.note`，前端 ⓘ 展示
- 用户级 API Key 采用 AES-GCM 加密存储（密钥仅存环境变量），响应永不回显明文，仅展示脱敏后 4 位尾号

**5. 全局深色模式与组件主题系统**
- 实现浅色/深色/跟随系统三态切换，顶栏圆形按钮循环切换，localStorage（`wt-theme`）持久化
- 基于 CSS 变量（`--wt-*`）+ `html.dark` 类实现双层主题，Element Plus 引入官方 dark css-vars 自动跟随
- 切换即时生效，带 0.25s 过渡动画；统计页 SVG 折线、游戏画布等取色均跟随主题变量
- 设计 18 项 Design Tokens（SD1–SD18），含主色/语义色/中性色/字体/间距/圆角/阴影/动效，暗色下三判定色对比度均 ≥ 6:1

**6. 词库三步异步导入与编码智能检测**
- 支持 CSV/TXT/XLSX 三种格式，≥1000 行时采用三步异步导入：上传 → 后台解析（chardet 自动检测 GBK/UTF-8 编码）→ 前端每 2s 轮询 jobId 展示进度
- 库内判重（spelling 忽略大小写唯一索引），重复词支持「覆盖」语义（仅更新释义/音标，不重置学习统计）
- 词库重分单元：支持双模式重组（每章词数 5–200 或单元数 2–500），词随机打散后顺序切分，仅重组章节不动统计
- 清空章节功能：一键删除全部章节但保留全部单词，支持后续重新分组

**7. 认证安全与管理后台**
- JWT 7 天有效期 + 滑动续期（剩余 <24h 时响应携带新 token，`X-New-Token` 响应头避免污染响应体）
- 改密/管理员重置 → `pwd_ver + 1`，JWT 载荷携带版本号，校验不一致即 401，实现多端同时失效
- 登录连续失败 5 次锁定 10 分钟，注册 IP 级限流 10 次/小时
- 全局中间件：POST/PUT/PATCH body 携带 `user_id` 一律 400（防止越权），用户身份一律从 JWT `sub` 提取
- 管理后台：用户管理、重置密码（临时密码一次性展示）、邀请码批量生成/停用、测试数据注入/清空面板

**8. 数据统计与可视化**
- 打卡热力图：DailyActivity 预聚合表，提交时实时 upsert，避免全表扫描
- LetterStat 指法分析：letter 字段支持 1–2 字符，单字母与相邻双字母（bigram）各自成行独立聚合，定位最慢/最常敲错的字母组合
- WPM 计算公式：正确字符数 ÷ 5 ÷ 有效输入分钟数，有效输入分钟数 = 首键→末键墙钟时间（默写卡展示期不计）
- 统计页含：熟练度分布饼图、WPM/准确率趋势折线、未来 7 天复习量预测、连续打卡天数
