# WordType 产品体验评估报告（普通用户视角）

> 评估日期：2026-09-17 · 方法：注册全新账号 uxtest57199，从注册页开始真实走完全部主流程（词库 → 学习 → 练习 → 复习 → 考核 → 游戏 → 统计 → 设置），全部截图存档于 `.workbuddy/ux-walkthrough/`。引用编号 D1–D33 对应《需求规格说明书 v3.4》。

## 结论摘要

产品的「引擎」已经很好：SM-2 复习、四种练习题型、考核、游戏、统计一应俱全。但以普通用户的第一小时体验来看，**上手门槛高、开发者痕迹重、文案与行为不一致**是三大主因。最优先要做的不是加功能，而是：修掉 3 个 P0 缺陷、清掉界面上的内部术语、给新用户一条 3 步上线路径。

---

## 一、功能多余（做减法）

| # | 问题 | 证据 | 建议 |
|---|------|------|------|
| 1 | **内部决策编号泄漏到用户界面**。「D8/D17」「D16 映射」「D13：切日以服务器为准」等字样直接出现在页面副标题和设置说明里，普通用户完全无法理解 | 学习页副标题「卡片自评 + 默写（D8/D17）」；设置页「自评（D16 映射）」「服务器日期…（D13…）」 | 全部移除或改为白话 tooltip；决策编号只留在需求文档 |
| 2 | **副标题是开发者备忘语言**。「词库 → 章节 → 单词 · 三步导入 · 克隆/导出」「四种题型 · 组内断点续练 · 离线重放」——「断点续练」「离线重放」是工程概念 | 词库页/练习页副标题 | 改成用户价值表述，如「三步导入你的词表，也可以直接用公共词库」 |
| 3 | **设置项一次性全部铺开**（15+ 项：每日额度×2、宽松判定、指法引导、TTS、组规格、复习形式、答错重现、释义显示、默写秒数、考核限时、及格线、考核宽松、游戏音效、AI 引擎、AI 凭据 5 字段），新手会被淹没 | 设置页整页滚动 | 分「常用 / 高级」两层：每日额度、复习形式、TTS 留在常用；其余收进「高级设置」折叠区 |
| 4 | **AI 模型配置过于极客**。API 基地址 / Key / 温度 / 超时 5 个字段对普通用户无意义，且默认引擎是规则，普通用户永远用不到 | 设置页「AI 模型配置（仅本人）」卡片 | 默认折叠为「高级：接入自己的 AI（可选）」 |
| 5 | **注册页邀请码字段**无来源说明，普通个人用户不知道去哪拿 | 注册页截图 | 折叠为「有邀请码？」展开框，并把「选填」说明写清 |
| 6 | **六个学习入口边界模糊**。学习 / 练习 / 复习 / 听写 / 考核 / 游戏，普通用户分不清「学习里的默写」「听写」「练习-释义→默写」三者差异 | 导航 12 个入口 | ① 导航按「今天要做的事」重组：今日学习（=学习+复习合并视角）/ 练习 / 挑战（考核+游戏）/ 词库 / 统计；② 或至少在各模式页头加一句「和 XX 的区别」说明 |

## 二、功能不足（有坑、粗糙）

| # | 严重度 | 问题 | 证据（可复现） | 建议 |
|---|--------|------|----------------|------|
| 1 | **P0** | **新用户被当成流失用户**：注册后仪表盘第一条建议是「连续 7 天未学习，来一份今日 10 分钟轻量计划找回节奏」——刚注册的用户从未学习过，文案完全错位 | 注册后仪表盘截图；代码 `misc_service.py` 第 ③ 条规则只判 `active==0`，未排除零历史新用户 | 建议规则排除「注册不足 7 天且从未学习」的用户，改为新手引导建议 |
| 2 | **P0** | **练习页文案与行为不符**：写着「多选章节（默认全选）」，实际一个都没选；直接点「开始练习」报错「请至少选择一个章节」；且未选词库时章节下拉为空、无任何「先选词库」提示 | 练习页截图 + 点击后 toast | 选词库后默认真·全选章节；未选词库时禁用开始按钮并提示 |
| 3 | **P0** | **考核配置「听音」数量控件显示不全**：1280px 宽度下「题型×量」一行换行，「听音」标签与数字框被拆开/截断，用户不知道还能配听音题 | 考核页截图；代码里 `el-input-number` 存在，是 flex 换行问题 | 题型数量改为网格布局，窄屏单列 |
| 4 | P1 | **忘记密码无自助路径**：登录页只有「去注册」，密码找回要找管理员。真实用户会被锁死在门外 | 登录页 | 短期：登录页加「请联系管理员重置密码」提示；中期：预留邮箱/安全问题通道 |
| 5 | P1 | **学习进度反馈不及时**：卡片自评（认识/模糊/不认识）后「今日新词 0 / 20」不更新，用户感觉操作没生效 | 自评后截图计数仍为 0 | 自评/默写提交后即时刷新计数 |
| 6 | P1 | **克隆是隐藏动作**：公共库对普通用户最重要的操作是「克隆一份变成我的」，但按钮与「导出 CSV」并排、无说明；克隆成功只弹「已克隆为副本（id 15）」——暴露内部 id，且不引导下一步「去学习」 | 词库页截图 | 克隆后 toast 加「去学习 →」按钮；id 不要展示 |
| 7 | P1 | **空状态没有下一步动作**：学习页空态只有一句「选择范围后开始学习」；错题本/统计空态同理，用户不知道该先去词库 | 各页空态截图 | 每个空态配一个行动按钮（「先去挑一个词库 →」） |
| 8 | P2 | **术语无解释**：「熟练度分布」的「巩固中 / 高危遗忘」、「额度 0 / 100 · 服务器日期」对普通用户是黑话 | 复习页/仪表盘 | hover tooltip 用白话解释（如「高危遗忘 = 快要忘掉的词，建议优先复习」） |

## 三、功能要补充（做加法）

| # | 优先级 | 建议 | 理由 |
|---|--------|------|------|
| 1 | **P0** | **新手引导**：首次登录后弹 3 步引导（① 在词库挑一本 → ② 学 5 个词 → ③ 回仪表盘看进度），完成任意一步打勾。也可用仪表盘空态清单替代 | 注册到第一次有效学习之间没有任何指路牌，这是「能不能用」的最大缺口 |
| 2 | **P1** | **今日目标进度条**：仪表盘顶部加一个合并的目标环（新词 + 复习），而不是四个零散的 0 数字 | 普通用户需要「今天做完了吗」的一眼答案；打卡热力图是回望，不是今日驱动 |
| 3 | **P1** | **单词搜索/查词入口**：全站没有按单词查询的地方，学过的词想回看释义只能等复习轮到它 | 词典类工具的基础预期；可挂在词库页顶部搜索框（目前只搜词库名） |
| 4 | **P1** | **结果页 → 错题本联动**：练习/考核结束页展示「本次错题已收入错题本 → 去看看」 | 错题本是现成功能，但用户可能从来不知道它被自动填充了 |
| 5 | **P2** | **复习提醒**：浏览器通知（本地）可选开关，或至少仪表盘显示「明日到期 x 词」前置预告 | SM-2 的价值依赖按时复习，目前全靠用户自觉回来 |
| 6 | **P2** | **练习/默写键盘流**：Enter 提交、自动聚焦下一个输入框的确认（若有则忽略） | 打字类产品的基本手感 |
| 7 | **P2** | **词库浏览页发音**：章节/单词管理里点单词能发音（学习卡上已有 🔊，管理页未必有） | 选词时需要听音判断要不要这个词 |
| 8 | **P2** | **移动端说明**：触屏设备上打字模式体验受限，至少在首页声明「建议电脑使用」，长期再做简化版移动流程 | 避免手机用户第一印象被毁 |

## 四、建议执行顺序

1. **本周可做（P0，全是小改动）**：修复新用户建议文案错位（#二1）、练习页默认全选+按钮禁用（#二2）、考核布局换行（#二3）、移除界面上的 D 编号（#一1）、克隆 toast 加跳转（#二6）。
2. **下一批（P1）**：新手引导三步清单、今日目标进度环、忘记密码提示、学习计数即时刷新、空态行动按钮。
3. **再往后（P2）**：术语 tooltip、单词搜索、错题联动、复习提醒、键盘流。
