以下为设计风格 · 配色 · 字体三体系的定稿文档（DS-Lock v1.0）。定位：对前述 DS v1.0 中「第二章 Design Tokens」的最终确认与校准——含 6 处基于对比度实测的修正（已列表），锁定后作为唯一视觉依据，组件与页面规范继续沿用 DS v1.0，冲突处以本文为准。决策编号 SD1–SD18，与需求侧 D1–D28 呼应，可直接进 Figma Variables 与 tokens.css。

设计风格与视觉体系定稿 v1.0
一、风格定稿
SD1 风格方向：「专注工作台 × 克制游戏感」
落点	定义
基调	大面积冷灰白中性面 + 单一品牌蓝，视觉重量比 70（中性）/ 20（品牌）/ 10（判定+强调）
训练域（学习/练习/复习/考核）	极简效率工具质感：轻描边、低阴影、零装饰，一切视觉资源让位给判定反馈
游戏域	允许暗色画布、粒子、火焰、连击动效——但被物理边界隔离在 Canvas 内，不外溢到 UI
情感温度	中性不冰冷：圆角偏柔、成就时刻允许弹性动效、插画为线性手绘感
SD2 候选方案淘汰记录（存档备查）
候选	淘汰/保留理由
重游戏化风（Duolingo 系：高饱和、大圆角、吉祥物）	✗ 判定三色会被装饰色淹没；成人用户长时间训练易视觉疲劳
纯极简冷风（Linear/Notion 系）	△ 作为底座保留；纯用则激励体系（连击/火焰/热力图）失去表现力
新拟态 / 玻璃拟态	✗ 对比度天然受损，与无障碍硬指标冲突；模糊渲染与 60fps Canvas 抢性能
✓ 专注工作台 × 克制游戏感	锁定：效率场景保专注，游戏场景给多巴胺，两者互不污染
SD3 形状语言
圆角：8（控件）/ 12（卡片）/ 16（弹窗）/ 999（标签）——中圆角，不做 iOS 式大圆角、不做锐角企业风
描边优先于阴影：默认 1px border-1 + shadow-1；浮层才升级 shadow-2/3
密度双轨：训练页 comfortable（答题区上下留白 ≥48px）/ 管理与列表页 compact（行高 48）
SD4 渐变白名单（仅 3 处，其余场景禁用渐变）
认证页品牌区背景（brand-500→700，135°）
游戏画布底（#14171B→#1B2026）
成就时刻（新纪录文字、火焰 Combo）
SD5 插画与图标
图标：Lucide（lucide-vue-next），24px 网格、stroke 1.5、圆帽圆角；尺寸 16/20/24 三档
例外：判定三图标（✓ ≈ ✗）为自绘 SVG，笔触与 Lucide 一致但独立维护（需与字体字形呼应）
插画：线性风格 stroke 1.5、brand-100 主调 + accent-500 点缀；空状态 4 张（词库空/队列空/词池空/无网络）
SD6 动效基调
全站 200ms 系标准曲线；击键反馈 0ms 直变（唯一无动画区）
成就/升级/销毁允许 spring（Overshoot ≤1.25 倍）
硬约束：任何动画不得引起布局位移（CLS=0，尤其判定 chip 与逐字格区域）

三、字体定稿
SD13 双字体策略
轨道	方案	理由
UI 界面（中文为主）	系统栈，不自托管 CJK 字体	CJK woff2 3–8MB，维护子集成本高；局域网部署环境以 Windows（微软雅黑）/ macOS（苹方）为主，系统栈渲染已达标；公网运营后再评估 MiSans 子集
单词展示 + 一切打字输入 + 数字统计	自托管 JetBrains Mono（OFL 开源，可商用嵌入）	全站唯一自托管字体；打字逐字格必须跨平台等宽对齐，系统等宽字体在 Win/mac/Linux 差异过大，不可接受
SD14 等宽字体选型记录
候选	结论
JetBrains Mono	✓ 高 x-height 屏显友好；0（内点）/1/l/I 区分度最佳——对打字产品是硬指标；OFL 协议；提供 variable font
Fira Code	✗ 默认连字会将 => != 等合并字形，打字训练中会让「输入了几个字符」产生视觉歧义，直接排除
Cascadia Code	△ 优秀但 Windows 生态绑定，作为 fallback 第一位
Roboto Mono / IBM Plex Mono	△ 合格备选，0/1 区分度弱于 JBM

SD17 排版细则
数字强制 font-variant-numeric: tabular-nums（所有统计/倒计时/额度/成绩；倒计时另加 mono）；
中文一律 letter-spacing: 0；拉丁单词展示可 +0.01em，逐字格必须 0；
中英混排行高以中文为准（22 系），避免西文行高导致中文裁切；微软雅黑行高偏大，行高一律显式声明、禁止继承默认；
单词永不断字；释义/例句单行省略 + tooltip；
中文回退：mono 栈不含 CJK，混排中文自动落回 ui 栈——符合预期，无需额外处理。
SD18 图标字体不引入
图标走 SVG 组件（Lucide），不引入 icon font：避免 FOUT 闪烁与打字页字体重排；判定三图标自绘 SVG 内联，保证 0ms 渲染。

四、Do / Don’t 速查
✓ Do	✗ Don’t
主按钮/链接用 brand-600/700	用 brand-500 承载 14px 白字
判定反馈三重冗余（图标+文案+色）	仅用颜色表达判定结果
判定色组合独占训练场景	用 ok/near/err 组合做营销横幅
accent 橙限制在游戏与激励	在考核、词库等效率场景撒橙色
一律显式行高、tabular 数字	继承浏览器默认行高、比例数字做倒计时
JetBrains Mono + 禁连字三件套	引入 Fira Code 或任一带连字等宽字体
冷灰中性面 + 单一品牌蓝	引入第二种品牌色相或大面积渐变
五、生效说明与验收
生效范围：本文锁定后取代 DS v1.0 中 2.1/2.2 节冲突项（校准 R1–R4）；SD1–SD18 为不可单方面变更项，调整需走评审并升版本号。
视觉走查清单（精简 8 项）：① 主按钮为 brand-600；② 判定 chip 文本对比 ≥4.5:1（吸色实测）；③ 逐字格同字符宽度跨 Win/mac 一致（三平台截图叠对）；④ 逐字格无连字（输入 => != 验证）；⑤ 所有数字 tabular；⑥ 暗色下三判定色辨识且对比 ≥6:1；⑦ 页面字体请求总数 ≤1 个字体文件；⑧ 全站未出现渐变白名单之外的渐变。
