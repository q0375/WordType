# 单词学习与打字速度练习系统 —— 结构化要点

## 一、项目定位
- 集背单词与打字速度练习于一体的 Web 应用。
- 前端技术栈：Vue 3 + Element Plus + Vite。
- 预览形态：单页应用（SPA），以 `location.hash` 路由（`#page=xxx`）切换页面。

## 二、必须实现的页面清单（按优先级与可见性）

### 用户认证
- **登录页** `/login`：用户名、密码、登录按钮；管理员入口提示。
- **注册页** `/register`：用户名、密码、确认密码；公网开关开启时显示邀请码。

### 核心学习
- **仪表盘 Dashboard**：顶部统计卡片（今日新词/复习/打卡/连续天数）、熟练度分布、近期趋势、AI 建议卡片、快捷入口。
- **学习模式 Study**：卡片展示单词/音标/释义/例句，自评三键（认识/模糊/不认识），默写卡（展示→隐藏→打字），TTS 开关，进度与额度提示。
- **练习模式 Practice**：题型选择（释义默写/四选一/听音拼写/例句挖空），组规格 10–50 题，答题区、判定反馈、WPM/准确率。
- **复习模式 Review**：今日复习队列，打字/选择/自评三种形式，答错当日重现开关。
- **考核模式 Exam**：倒计时、进度、题型、交卷、成绩单。
- **游戏模式 Game**：下落单词打字游戏，Canvas 渲染，血量/Combo/分数/暂停/结算。

### 词库与数据
- **词库管理 Books**：词库列表、章节、单词增删改、搜索、虚拟滚动、导出/克隆/导入入口。
- **导入流程 Import**：上传 → 预览（成功/重复/错误行） → 确认入库，重复策略跳过/覆盖。
- **错题本 WrongBook**：错词列表、攻克计数、pin/移除、重练入口。

### 个人与系统
- **个人中心 Profile**：修改密码、数据导出、账号注销、学习统计摘要。
- **设置 Settings**：每日新词/复习额度、严格/宽松、TTS、指法引导、复习形式、游戏难度、考核限时及格线等。

### 管理员
- **用户管理 AdminUsers**：用户列表、重置密码、恢复软删。
- **邀请码管理 AdminInviteCodes**：批量生成、列表、停用。
- **AI 配置 AdminAI**：API 基地址、模型名、温度、超时、连通性测试、key 脱敏展示。

## 三、共享数据契约（前端 localStorage + 组件状态）
- 当前用户：`currentUser` { id, username, role }。
- 设置：`typing-settings` { daily_new_limit, daily_review_limit, loose_match, tts_on, review_form, dictation_show_seconds, practice_group_size, game_difficulty, game_limited_mode, exam_time_limit, exam_pass_score, exam_loose_match, review_wrong_reshow }。
- 练习进度：`{userId}:practice:{sessionId}`。
- pending 重放队列：`{userId}:pending`。
- 词库/学习数据使用模拟数据集合，字段严格对齐数据模型。

## 四、统一视觉主线
- 主色：科技蓝 `#2563EB`（Element Plus primary 覆盖）。
- 辅色：成功绿 `#10B981`、警告橙 `#F59E0B`、危险红 `#EF4444`、中性灰 `#F3F4F6`。
- 背景：浅灰 `#F8FAFC`，卡片白底圆角阴影。
- 字体：系统无衬线，标题字重 600。
- 布局：顶部固定导航 + 主内容区最大宽度 1200px 居中；移动端汉堡菜单。
- 游戏页面全屏沉浸式，其余页面统一容器。

## 五、导航结构（顶部导航）
- 左侧 Logo + 应用名
- 中部：仪表盘、学习、练习、复习、考核、游戏、词库、错题本
- 右侧：设置、个人中心、退出（未登录时显示登录/注册）
- 管理员额外：用户管理、邀请码、AI 配置

## 六、关键交互约定
- 所有页面跳转使用 `#page=xxx`，禁止 `location.href/assign/replace`。
- 按钮、表单、标签页使用 Element Plus。
- 功能图标统一使用 Element Plus 图标（通过 `<el-icon>`），禁止 emoji/自绘图标。
- 游戏使用 Canvas 渲染，键盘事件驱动。
- 数据可视化使用 ECharts（已确认需求提及）；但模板未内置 ECharts，本次使用简单 CSS/HTML 图表或按需引入，避免无关依赖。
- 使用模拟数据，不请求真实后端接口。

## 七、构建与验证
- 依赖：element-plus + vue。
- 构建命令：`pnpm run build`（或 npm）。
- 产物检查：`app/dist/index.html` 必须存在。
